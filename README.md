# Rebalancing Capital and Labour

Comparative economic paper evaluating Australia's pre-Budget framework, Allegra Spender's Personal Tax White Paper and the 2026-27 Federal Budget CGT and negative-gearing reforms.

## Files

- `paper.md`: academic-style paper, policy analysis and scenario results
- `model/cgt_policy_model.py`: deterministic microsimulation
- `model/cgt_policy_results.json`: calculated liabilities, cash flows and returns
- `model/policy_source_manifest.json`: source links and local-source hashes

Run the model with `python3 model/cgt_policy_model.py`. It uses only the Python standard library. The scenarios are illustrative partial-equilibrium calculations, not forecasts or individual tax advice.
